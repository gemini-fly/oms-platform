钉钉连接配置

字段来源：CorpId 在钉钉开发者后台首页查看；AppKey、AppSecret、AgentId 在“应用开发 / 企业内部应用 / 应用详情”的基础信息或凭证信息中查看。 根部门 ID 默认填 1，表示从企业根部门同步；只同步某个部门时填写钉钉通讯录里的部门 ID。启用前需要给该企业内部应用开通通讯录读取相关权限。
